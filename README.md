# Tic-Tac-Toe Game in C

Tic-tac-toe game written in C.

## How to run

1. Download source code
2. On Windows, run ttt.exe
3. On Linux (or Mac, untested): run ttt
    1. Might have to do `chmod +x ttt`

## How to compile

*NOTE:* This Tic-Tac-Toe project is compatible with C99 and newer.

1. Ensure GCC is installed on your system.
2. Download or clone the source code
    1. `git clone https://github.com/codezinx/tic-tac-toe-c.git`
3. Compile with latest C using:
    1. `gcc ttt.c -o ttt` on Mac / Linux
    2. `gcc ttt.c -o ttt.exe` on Windows
